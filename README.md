# Basic File Handling in Java

This project demonstrates basic file handling in Java by reading data from a text file and displaying it in the console.

## Features

- Reads content from a text file
- Displays file content in console
- Uses Scanner class for file reading
- Handles file-related exceptions

## Technologies Used

- Java
- IntelliJ IDEA
- Git & GitHub

## Project Structure

```text
BasicFileHandling/
│
├── src/
│   └── BasicFileHandling.java
│
├── sample.txt
├── .gitignore
├── README.md
└── BasicFileHandling.iml
```

## Java Code Overview

The program:

- Opens a text file
- Reads file content line by line
- Displays content in the console
- Uses try-catch for exception handling

## Sample File Content

```text
Learning Java is fun!
```

## Sample Output

## How to Run

1. Open the project in IntelliJ IDEA
2. Make sure `sample.txt` exists in the project folder
3. Open `BasicFileHandling.java`
4. Click the Run button
